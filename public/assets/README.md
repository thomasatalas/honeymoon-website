# Public Assets Structure

This folder is reserved for asset files used by the honeymoon website.

## Folder guide

- `hero/` — hero and cover imagery
- `proposal/` — proposal-related images
- `shanghai/` — Shanghai wedding imagery
- `napa/` — Napa wedding imagery
- `hangzhou/` — Hangzhou travel imagery
- `flights/` — airline brand assets and travel media
- `hotels/` — hotel photography and brand visuals
- `food/` — restaurant and food photography
- `attractions/` — destination attractions and sightseeing imagery
- `journals/` — journal entries, notes, and story media
- `videos/` — video files and visual clips
- `misc/` — miscellaneous supporting art
- `metadata/` — JSON, YAML, or schema metadata for content lookup
